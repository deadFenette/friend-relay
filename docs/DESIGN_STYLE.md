# Дизайн-гайд: «Spatial Glass»

Визуальный и поведенческий эталон Qt-клиента. Все новые экраны и виджеты
сверяются с этим документом; расползания стилей между экранами не должно
быть.

## Философия

Гибрид macOS Fluent, Windows 11 Mica и дозированного неоморфизма — но
исключительно средствами PySide6-виджетов, без QML и WebEngine.
Ощущение от приложения:

- **Лёгкость** — мгновенный старт (до первого кадра < 200 мс), ничего
  лишнего на экране;
- **Тактильность** — кнопки продавливаются, переключатели ездят, списки
  имеют инерцию;
- **Уважение к пользователю** — никаких модалок-спама; для обратимых
  действий подтверждения не спрашиваем;
- **Дружелюбность к OLED** — честный тёмный режим с семантическими
  уровнями elevation, а не просто заливка `#000`.

Чего не делаем (уроки чужих клиентов):

- **Anti-Discord** — панели не вкладываются глубже двух уровней; боковые
  панели — контекстные и умеют сворачиваться;
- **Anti-TeamSpeak** — никакой криптовой иерархии деревом; навигация —
  плоские человекочитаемые «Spaces» с иконками;
- **Anti-Telegram** — скрытые жесты не могут быть единственным способом
  что-то сделать; у каждого жеста есть видимая альтернатива;
- **Anti-ICQ** — никакого фичекрипа: фича, требующая туториала,
  переделывается или выкидывается.

## Технические ограничения

- **Фреймворк:** PySide6 (Qt 6.5+), чистое `QWidget`-приложение.
  QML и WebEngine не используем.
- **Стилизация:** сторонние QSS-темы (qdarkstyle и подобные) запрещены —
  только собственная система `QPalette` + QSS с CSS-подобными переменными.
- **Анимация:** всё движение — через `QPropertyAnimation`,
  `QParallelAnimationGroup` и `QEasingCurve`. Таймерные хаки не допускаются.
- **Графика:** кастомные виджеты рисуются в `QPainter`.
  `QGraphicsDropShadowEffect` — не чаще одной тени на вид
  (blur=20, цвет с непрозрачностью 15%).
- **Производительность:** цель — 60 fps; анимируем только geometry/pos/
  windowOpacity (аналоги transform/opacity), пересчётов layout во время
  анимации нет.

## Архитектура окна и переходы

Один `QMainWindow`; все экраны — страницы кастомного
`SlidingStackedWidget` («колода»).

Переходы:

1. **Cross-Fade** — навигация между равноправными разделами (табы
   настроек): 180 мс, `OutCubic`.
2. **Horizontal Slide** — drill-down (список чатов → комната): 250 мс,
   `InOutQuart`; исходящий экран уезжает влево, сжимаясь до 0.9 и гасня,
   входящий — справа в полном масштабе.
3. **Vertical Push** — модалки и оверлеи (профиль пользователя): 300 мс,
   `OutBack` с лёгким «перелётом».
4. **Morph** — контекстные действия (FAB → окно создания): общие элементы
   анимируются геометрией между состояниями.

Хром окна:

- **Frameless с уважением к платформе** — свой тайтлбар на Windows/Linux;
  на macOS остаются нативные «светофоры» (выбор по платформе через
  `Qt.WindowType.CustomizeWindowHint`).
- **Snap Layouts** на Windows 11 обязан работать: корректный
  `WM_NCHITTEST` + нативные тени (либо `FramelessWindowHint` с
  shadow-margins).

## Макет: три зоны

Никакой «панели-ада»:

| Зона | Поведение | Содержимое |
|------|-----------|------------|
| **Rail (64px)** | Всегда видна, только иконки; при наведении раскрывается до 240px с подписями (200 мс slide). | Spaces, ЛС, настройки |
| **Canvas (резиновая)** | Основное содержимое; плотность меняется по ширине окна (брейкпоинты 800 и 1200px). | Чат, панели настроек |
| **Palette (до 320px)** | Контекстная панель справа; на узких окнах прячется, выезжает slide-in. | Список участников, инфо о пользователе |

Responsive-правила:

- < 800px — Rail перекладывается вниз как «bottom tab bar» (компактный
  режим, но всё ещё десктопное приложение);
- 800–1200px — Rail + Canvas; Palette живёт как выезжающий оверлей;
- > 1200px — все три зоны, Palette пришвартована.

## Библиотека компонентов

Переиспользуемые `QWidget`-подклассы со своим `paintEvent`:

### GlassButton
- Фон `rgba(255,255,255,0.06)`, бордер 1px `rgba(255,255,255,0.1)`;
- hover: фон до `0.12` + лёгкая приподнятая тень;
- press: масштаб до 0.97, тень схлопывается;
- радиус углов 8px — единый для всех компонентов.

### ChannelPill
- Замена списку каналов: пилюля, а не элемент дерева;
- непрочитано: акцентная полоса слева (3px) + мягкое свечение фона, без
  красных точек;
- активный канал: полная заливка фона, жирный текст;
- hover: сдвиг на +4px.

### MessageBubble
- Без жёстких бордеров — только разница elevation;
- группировка сообщений одного автора: «хвост» только у последнего бабла,
  аватары выравниваются по последнему;
- hover раскрывает строку действий (ответить/реакция/ещё) со staggered
  fade-in — каждая следующая иконка с задержкой 40 мс.

### ContextualAppBar
- Замена статических верхних панелей: появляется при выделении текста
  или мультивыборе;
- материал: полупрозрачный `QWidget` (blur-behind на чистых виджетах
  честно не делается);
- анимация: падение сверху с `OutBack`, 200 мс.

## Цвет и типографика

Палитра (тёмная по умолчанию):

```python
SURFACE_0 = "#0B0B0F"      # самый глубокий фон
SURFACE_1 = "#121218"      # карточки, панели
SURFACE_2 = "#1C1C24"      # приподнятые hover-состояния
SURFACE_3 = "#272730"      # активные поля ввода
ACCENT = "#7C6BFF"         # основное действие (перванш — отличим от «дискордовского» блюпла)
ACCENT_GLOW = "rgba(124,107,255,0.25)"
TEXT_PRIMARY = "#F0F0F5"
TEXT_SECONDARY = "#8E8E99"
SUCCESS = "#34D399"
DANGER = "#FB7185"
```

Типографика: системный стек шрифтов (-apple-system, BlinkMacSystemFont,
"Segoe UI", Roboto, Ubuntu). Шрифт меньше 12px не используем;
системные настройки доступности уважаем (масштаб через QFontDatabase).

## Микровзаимодействия

«Живой» интерфейс:

- у любого действия есть обратная связь: кнопка «копировать» на полторы
  секунды превращается в галочку и возвращается обратно;
- загрузка — скелетоны с пробегающим бликом (QPropertyAnimation по точкам
  QLinearGradient), а не крутящиеся колёса;
- индикатор «печатает» — три точки, перетекающие волной (масштаб +
  прозрачность со сдвигом фазы), а не простое мигание;
- голосовая активность — не статичная иконка: радиальная пульсация вокруг
  аватара, реагирующая на громкость (кольцо в QPainter);
- новое сообщение: появление снизу на 8px + fade за 150 мс; если бабл вне
  экрана — кнопка «вниз» мягко пульсирует.

## Навигация и обнаруживаемость

- **Command Palette (Ctrl+K)** — spotlight-оверлей с затемнённой
  подложкой; ищет по разделам, ЛС, настройкам и действиям. Основной
  инструмент опытного пользователя.
- **Предсказуемые шорткаты** — Ctrl+1..9 для пунктов Rail,
  Ctrl+Shift+T для последнего ЛС; Esc всегда закрывает оверлей или
  выходит из режима.
- **Никаких скрытых свайпов**: если панель можно свайпнуть, у неё есть
  видимая кромка 3px с подсказкой при наведении.
- **Онбординг** — не слайдшоу, а контекстные подсказки-стрелки у реальных
  элементов интерфейса, когда фича впервые становится уместной.

## Доступность и системная интеграция

- Уважаем `QGuiApplication.styleHints().colorScheme()` и режим
  принудительных цветов (forced-colors);
- скринридеры: все кастомные виджеты реализуют QAccessibleInterface,
  кнопки не имитируются QLabel'ами;
- ОС-уведомления — нативные средства платформы; собственные попапы
  допустимы только если ОС отказала в разрешении;
- на Windows при возможности включаем Mica/Acrylic через
  DwmSetWindowAttribute; фолбэк — сплошной SURFACE_1.
