# MusicBot — музыкальный бот для Friend Relay

MusicBot позволяет воспроизводить музыку синхронно для всех участников голосового канала.

## Возможности

- **Локальные файлы** — поддержка MP3, FLAC, OGG, WAV, M4A
- **Очередь треков** — добавление, удаление, пропуск
- **Синхронное воспроизведение** — все слышат одно и то же одновременно
- **Система прав** — хост и админы управляют, остальные добавляют в очередь
- **Веб-клиент** — автоматическая синхронизация при подключении к голосу

## Установка

### 1. Добавление бота

Хост добавляет бота через вкладку "Боты" в интерфейсе:
- В поле "ID бота" введите: `music`
- Нажмите "Добавить"

### 2. Настройка директории с музыкой

Хост указывает путь к папке с музыкой через команду в чате:
```
!music setdir C:/Users/Имя/Music
```

Бот автоматически просканирует папку и найдёт все поддерживаемые аудиофайлы.

### 3. Проверка библиотеки

```
!music list
```

Покажет первые 20 треков из библиотеки.

## Команды

### Управление воспроизведением (хост/админ)

```
!music play <track_id>    — играть трек
!music pause              — пауза
!music skip               — следующий трек из очереди
!music volume <0-100>     — громкость (по умолчанию 70)
```

### Очередь (все участники)

```
!music queue              — показать очередь
!music add <track_id>     — добавить трек в очередь
!music remove <index>     — удалить из очереди (хост/админ)
```

### Библиотека

```
!music list               — показать доступные треки
!music setdir <path>      — установить папку с музыкой (хост)
```

### Управление правами (хост)

```
!music admin add <name>   — добавить админа
!music admin remove <name> — удалить админа
```

## Примеры использования

### Базовый сценарий

1. Хост устанавливает директорию:
   ```
   !music setdir C:/Music
   ```

2. Хост смотрит библиотеку:
   ```
   !music list
   ```
   ```
   🎵 Библиотека (первые 20):
     1. song1 (song1.mp3)
     2. song2 (song2.flac)
     ...
   ```

3. Хост запускает трек:
   ```
   !music play song1
   ```
   ```
   🎵 Играю: song1.mp3
   ```

4. Друг добавляет в очередь:
   ```
   !music add song2
   ```
   ```
   📝 Добавлено в очередь (позиция 1): song2.flac
   ```

5. Хост пропускает текущий трек:
   ```
   !music skip
   ```

### Управление админами

Хост добавляет друга как админа:
```
!music admin add Вася
```
```
✅ Вася теперь админ музыки.
```

Теперь Вася может управлять воспроизведением.

## Веб-клиент

Музыка автоматически синхронизируется в веб-клиенте при подключении к голосовому каналу:

1. Откройте вкладку "Голос"
2. Нажмите "Подключиться"
3. Музыка начнёт воспроизводиться синхронно с сервером

Синхронизация происходит каждые 5 секунд.

## API

### HTTP эндпоинты

#### GET /music/sync

Возвращает текущее состояние воспроизведения.

**Ответ:**
```json
{
  "ok": true,
  "playing": true,
  "track_id": "song1",
  "filename": "song1.mp3",
  "position": 45.7,
  "is_playing": true,
  "volume": 70
}
```

#### GET /music/library

Возвращает библиотеку доступных треков.

**Ответ:**
```json
{
  "ok": true,
  "tracks": [
    {
      "id": "song1",
      "path": "C:/Music/song1.mp3",
      "filename": "song1.mp3",
      "size": 5242880
    }
  ]
}
```

#### GET /music/stream/<track_id>

Стриминг аудио файла с поддержкой Range запросов.

## Конфигурация

### На сервере

Путь к музыке хранится в данных бота:
```python
# ~/.friend_relay/relay_data/bots/music_data.json
{
  "music_dir": "C:/Music",
  "volume": 70,
  "queue": [],
  "admins": ["Вася"]
}
```

### Константы (lib/constants.py)

```python
MUSIC_DIR_NAME = "music"
MUSIC_SUPPORTED_FORMATS = {".mp3", ".flac", ".ogg", ".wav", ".m4a"}
MUSIC_MAX_FILE_SIZE = 100 * 1024 * 1024  # 100 МБ
MUSIC_SYNC_INTERVAL_MS = 5000  # 5 секунд
```

## Интеграция с облачными библиотеками

Для интеграции с облачными библиотеками (SoundCloud, Bandcamp и т.д.):

1. Расширьте метод `_scan_library()` в `lib/bots/music.py`
2. Добавьте API-клиент для облачного сервиса
3. Реализуйте кэширование треков локально
4. Используйте существующий стриминг через `/music/stream/<track_id>`

Пример для SoundCloud:
```python
def _scan_library(self) -> None:
    # Локальные файлы
    for file_path in self.music_dir.rglob("*"):
        # ... существующий код ...
    
    # SoundCloud плейлист
    if self.soundcloud_playlist_id:
        tracks = self._fetch_soundcloud_playlist()
        for track in tracks:
            self.library[track["id"]] = {
                "id": track["id"],
                "path": None,  # стримим напрямую
                "url": track["stream_url"],
                "filename": track["title"],
            }
```

## Ограничения

- **Только веб-клиент** — Qt-клиент пока не поддерживает музыку
- **Локальные файлы** — файлы должны быть на диске хоста
- **Форматы** — поддерживаются только MP3, FLAC, OGG, WAV, M4A
- **Размер** — максимальный размер трека 100 МБ

## Траблшутинг

### Музыка не воспроизводится

1. Проверьте, что бот добавлен: вкладка "Боты"
2. Проверьте директорию: `!music setdir <path>`
3. Проверьте библиотеку: `!music list`
4. Проверьте, что вы подключены к голосовому каналу

### Треки не находятся

1. Убедитесь, что файлы в поддерживаемых форматах (MP3, FLAC, OGG, WAV, M4A)
2. Проверьте путь к директории: `!music setdir`
3. Перезапустите бота (удалите и добавьте снова)

### Синхронизация не работает

1. Проверьте, что веб-клиент подключен к голосу
2. Откройте консоль браузера (F12) и проверьте ошибки
3. Убедитесь, что `/music/sync` возвращает корректные данные
