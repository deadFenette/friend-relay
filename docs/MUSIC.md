# 🎵 Музыка в Friend Relay v3.3.0

Синхронное прослушивание: **хост стримит треки — все гости слушают один и
тот же трек в одно и то же время — и любой гость может выбрать следующий**.

Всё работает через уже поднятый сервер Friend Relay: никаких отдельных
сервисов, портов и программ. Гости открывают обычную веб-страницу чата и
переключаются на вкладку **«Музыка»**.

---

## Как хосту включить (30 секунд)

1. Запусти приложение как обычно (`RUN.bat`).
2. Рядом с приложением появится папка **`relay_data/music/`** — закинь туда
   свои треки: `mp3`, `flac`, `ogg`, `wav`, `m4a` (до 100 МБ на файл,
   вложенные папки сканируются тоже).
3. Готово. Веб-клиенты нажимают «Обновить библиотеку» на вкладке «Музыка»
   и видят твои треки.

Свою папку (например, большую коллекцию на другом диске) можно назначить:
- в чате: `!music setdir D:\Музыка` — от имени хоста;
- программно: `POST /music/settings {"music_dir": "D:\\Музыка"}`.

> Установи `pip install mutagen` на хосте — треки получат длительность,
> артиста и название из тегов, а переход между треками станет мгновенным.
> Без mutagen всё тоже работает, просто длительность неизвестна и переход
> происходит по отчётам браузеров «трек докатился».

## Как это выглядит у гостей

Вкладка «Музыка»:

- **Карточка «сейчас играет»** — название/артист, полоса прогресса (клик —
  перемотка), пауза/плей, «следующий», локальная громкость (слышна только
  тебе, хранится в браузере).
- **Очередь** — общий список «что сыграет дальше» с именами тех, кто
  заказал. Свою заявку можно убрать, чужую — только хост/админ.
- **Библиотека** — поиск по названию/артисту/папке. Клик по треку —
  играть сейчас; кнопка **+** — добавить в очередь.
- Если браузер блокирует автозапуск (так делают все современные браузеры
  до первого клика на странице) — появится кнопка **«Слушать со всеми»**,
  один клик — и синхронизация поймалась.

### Права (режимы)

| Режим | play/pause/skip/перемотка | очередь | кто переключает |
|---|---|---|---|
| **open-DJ** (по умолчанию) | все гости | все гости | любой — сервер считает «кто последний нажал» |
| **закрытый** (`!music opendj off`) | только хост и админы музыки | все гости | хост/админы |

Админов назначает хост: `!music admin add Имя`. Хост — всегда админ.

### Синхронизация — как не рассинхрониться

Сервер считает позицию от **своих часов** и отдаёт её вместе с
`server_time` и `state_version`. Клиент каждые 2.5 секунды сверяется:
если локальный плеер ушёл больше чем на 1.5 секунды — тихо
подматывается. Услышать «у друга уже припев, а у меня куплет» можно
только при просадке сети — тогда позиция дотянется сама.

Конец трека: как только у любого слушателя аудио докатилось до конца,
браузер сообщает серверу (`POST /music/ended`), и сервер переключает
**всех** на следующий трек очереди. Параллельно то же самое делает
внутренний таймер сервера, если известна длительность.

## Внешние библиотеки (задел на «самую большую библиотеку»)

В строке поиска вкладки «Музыка» нажми **Enter** — запрос уйдёт во
внешние API. Модуль `lib/music_library.py` уже умеет:

| Провайдер | Ключ | Что даёт |
|---|---|---|
| **iTunes Search** | не нужен, включён сразу | честные метаданные + 30-секундные превью m4a: можно послушать прямо во вкладке и импортировать в библиотеку хоста |
| **Jamendo** | бесплатный `client_id` с devportal.jamendo.com | полные треки независимых артистов (лицензия CC), можно импортировать |

Включить Jamendo: создай файл `relay_data/music_api.json`:

```json
{
  "jamendo": {"enabled": true, "client_id": "ТВОЙ_CLIENT_ID"}
}
```

Добавить нового провайдера (Spotify-совместимый каталог, своё облако и
т.п.) — один класс с методом `search()` в `lib/music_library.py`,
регистрация в словаре `_PROVIDERS`. Никакие другие файлы трогать не нужно.

Импорт скачивает файл **на хост** (в папку библиотеки) фоновым потоком и
пересканирует библиотеку — через несколько секунд трек увидят все.

## HTTP API (для своих скриптов)

Все POST-эндпоинты требуют стандартную подпись `X-Relay-Auth` (как
остальные маршруты); `sender` — проверенное имя из сессии.

| Маршрут | Тело | Что делает |
|---|---|---|
| `GET /music/library` | — | список треков (id, title, artist, duration…) |
| `GET /music/sync` | — | состояние: track, position, playing, queue, open_dj, server_time, state_version |
| `GET /music/stream/<id>` | — | аудиофайл с поддержкой Range (перемотка работает) |
| `POST /music/play` | `{"track_id":"…","position":0}` | играть (без track_id — возобновить) |
| `POST /music/pause` | `{}` | пауза |
| `POST /music/skip` | `{}` | следующий из очереди |
| `POST /music/seek` | `{"position":123}` | перемотка (сек) |
| `POST /music/queue/add` | `{"track_id":"…"}` | в очередь (если ничего не играет — стартует сразу) |
| `POST /music/queue/remove` | `{"index":1}` | убрать заявку (свою — автор, чужую — админ) |
| `POST /music/ended` | `{}` | отчёт «трек закончился» |
| `POST /music/rescan` | `{}` | пересканировать папку |
| `POST /music/settings` | `{"music_dir":"…","open_dj":true}` | настройки (только хост) |
| `POST /music/api/search` | `{"query":"…","provider":"itunes"}` | поиск во внешних API |
| `POST /music/api/import` | `{"provider":"itunes","track_id":"…"}` | скачать трек в библиотеку хоста |

## Команды чата

```
!music list                — библиотека хоста
!music play <id>           — играть
!music pause / skip        — пауза / следующий
!music add <id>            — в очередь (все)
!music queue               — очередь с авторами
!music search <запрос>     — поиск во внешних API
!music setdir <путь>       — папка с музыкой (хост)
!music opendj on|off       — режим управления (хост)
!music volume <0-100>      — громкость по умолчанию (хост)
!music admin add <имя>     — админ музыки (хост)
!music rescan              — пересканировать папку
```

## Частые вопросы

**Треков не видно.** Хост: проверь, что файлы лежат в `relay_data/music/`
(или папка назначена через `!music setdir`), нажми «Обновить библиотеку».
Папка сканируется при старте сервера и по кнопке — новые файлы сами
появятся только после обновления.

**Не играет и висит «Слушать со всеми».** Браузер запретил автоплей —
нажми кнопку. Это ограничение всех браузеров, не баг.

**Музыка и голос вместе?** Да: голос идёт через голосовой канал,
музыка — потоком с хоста в браузер. Слушать музыку в наушниках с
открытым микрофоном не советуем — микрофон услышит музыку из колонок.
