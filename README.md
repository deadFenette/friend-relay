# Friend Relay

[![tests](https://github.com/deadFenette/friend-relay/actions/workflows/ci.yml/badge.svg)](https://github.com/deadFenette/friend-relay/actions/workflows/ci.yml)

Свой чат для своих: текст, голос, файлы, игры — сервер крутится на твоём
компьютере, без облаков и посередине никого. Хост запускает сервер, друзья
заходят браузером или Qt-клиентом через локалку / ZeroTier / Tailscale.

Актуальная версия — PySide6 (`RUN.bat` или `python main_qt.py`).
Старая Tkinter-версия лежит в `legacy/tkinter/`.

## Быстрый старт

1. Python 3.11+, зависимости: `pip install -r requirements.txt`
2. Хост: `RUN.bat` (GUI) или `python server_main.py --name Емеля --key ключ` (консоль)
3. Друзья открывают в браузере `http://<адрес-хоста>:8420`
   — адрес печатается при старте сервера (LAN, ZeroTier, Tailscale)
4. Админ — тот, кто вошёл под именем хоста: на машине хоста сразу,
   с другого устройства — с ключом админа (печатается в шпаргалке при старте)

HTTPS работает из коробки (самоподписанный сертификат создаётся сам,
браузер один раз спросит «перейти всё равно») — микрофон и уведомления
требуют secure context, так что заходить лучше по `https://`.

## Что умеет

- Голос с шумодавом RNNoise, рация (PTT — V/Пробел/кнопка), «кто говорит»
- Текст, ЛС, каналы, реакции, пины, поиск по всей истории
- Файлы и скриншоты: drag&drop, превью, лайтбокс; лимит размера настраивается
- Шифрование AES-256-GCM (`--encryption`), ключ доступа на вход
- ОС-уведомления о новых сообщениях, темы и скины
- Музыка-бот с синхронизацией, игры (змейка, орбиталка, шахматы),
  воксельный шутер

## Сервер без GUI: основные параметры

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `--name` | из settings.json | имя хоста (= админ) |
| `--port` | 8420 | HTTP/HTTPS порт (голос +1, voxel +2) |
| `--key` | — | ключ доступа (пусто = открытый сервер) |
| `--max-file-size` | 2G | лимит файла: `2G`, `1.5GB`, `500M`, `2048` (голое число — МБ) |
| `--bind` | 0.0.0.0 | интерфейс прослушивания (`127.0.0.1` — только локально) |
| `--admin-key` | авто | ключ админа для входа с других устройств |
| `--encryption` | выкл | AES-256-GCM шифрование сообщений |
| `--quiet` | — | без стартовой шпаргалки (systemd/службы) |

Приоритет лимита файла: `--max-file-size` > `--max-mb` (старый флаг) >
`max_file_size_mb` в settings.json (туда пишет GUI-хост) > 2 ГБ.
Полный список — `python server_main.py --help`.

## Тесты и CI

```bash
python scripts/run_all_tests.py          # весь набор (таймаут на каждый тест)
python scripts/run_all_tests.py --ci     # режим CI с аннотациями GitHub
```

GitHub Actions: push/PR в main, Python 3.11/3.12 (бейдж вверху).
